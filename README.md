README — Слайдер изображений
=====================================================

ФУНКЦИОНАЛ

1. Добавление изображений
   - Поле ввода принимает прямой путь к изображению.
   - Кнопка "Добавить" (или клавиша Enter) добавляет изображение в общий список (пул) и сразу отмечает его как выбранное для показа.
   - Если поле пустое - выводится подсказка "Введите ссылку или путь к изображению."
   - Если изображение по ссылке не загрузилось - выводится подсказка "Не удалось загрузить изображение по этой ссылке."

2. Выбор изображений для показа
   - Все добавленные изображения отображаются миниатюрами в сетке.
   - Клик по миниатюре включает/выключает изображение из показа в слайдере без удаления его из общего списка.
   - Выбранные миниатюры показаны ярко с галочкой, невыбранные - затемнены.

3. Удаление изображений
   - На каждой миниатюре есть кнопка-крестик.
   - Клик по крестику полностью удаляет изображение из списка.

4. Навигация по слайдеру
   - Кнопки "вперёд" и "назад" переключают текущее изображение.
   - Навигация зациклена: после последнего изображения показывается первое, а перед первым - последнее.
   - Кнопки расположены в отдельном ряду под областью изображения.

5. Счётчик
   - Под областью изображения отображается текст, показываюший номер текущего и общее колличество изображений. 
   - Если ни одно изображение не выбрано, вместо счётчика показывается сообщение "Нет выбранных изображений".

6. Адаптивный размер окна просмотра
   - Область показа изображения подстраивает свою высоту под реальные пропорции (соотношение сторон) каждой конкретной картинки.
   - Высота кадра ограничена сверху и снизу, чтобы очень широкие или очень высокие изображения не искажали и не "ломали" интерфейс.

7. Устойчивость к переполнению экрана
   - Если содержимое (кадр + панель выбора + поле добавления ссылки) не помещается по высоте, появляется собственная внутренняя прокрутка внутри карточки слайдера.

ТЕХНИЧЕСКИЙ СОСТАВ
------------------
- HTML - структура: заголовок окна, область изображения, кнопки навигации, счётчик, панель миниатюр, поле добавления ссылки.
- CSS - оформление в стиле Windows 7 Aero (градиенты, тени, полупрозрачность через backdrop-filter, шрифт Segoe UI).
- JavaScript - вся логика: хранение списка изображений, отслеживание выбранных, переключение слайдов, зацикливание, динамический расчёт пропорций кадра, обработка ошибок загрузки изображений.
